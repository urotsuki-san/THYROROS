# THYROROS Mascot / README Hero Art

Status: **adopted**

The current THYROROS README hero is:

```text
docs/assets/readme/thyroros-showcase-hero-v1.png
```

It follows the project-family visual language used for public README heroes: a dark flat background, sparse product copy on the left, a single pixel-art character on the right, and a restrained circular technical backdrop. The image should feel like a product identity surface rather than a decorative anime illustration.

## Character identity

The THYROROS character is the project's gatekeeper, not a generic cyber-assistant.

Current distinguishing traits:

- short icy blue / silver-blue bob hair;
- warm amber-gold eyes;
- a small rectangular teal-and-gold gate/key hair ornament;
- dark hooded long coat with cyan piping and restrained gold accents;
- Greek-key geometric trim near the coat hem;
- white shirt, teal necktie, dark pleated skirt, and dark boots;
- small credential / gate-access devices integrated into the outfit;
- a glowing access-key card held in one hand;
- calm, slightly confident, approachable expression rather than an aggressive security posture.

The palette is intentionally different from generic blue-neon security art:

- near-black navy for the field and coat;
- cyan / teal as the dominant project accent;
- warm gold as a secondary authority / verification accent;
- off-white only for readable highlights and shirt details.

## Hero composition

The adopted hero uses the following hierarchy:

```text
THYROROS
AGENT RUNTIME GATE
& FLIGHT RECORDER

IMMUTABLE CONTRACTS  •  MEDIATED EFFECTS  •  VERIFIABLE RECEIPTS

EXTERNAL REFERENCE MONITOR  /  FAIL-CLOSED BY CONTRACT
```

Composition rules:

- product mark and copy stay on the left;
- the character stays on the right;
- a circular gate / scope backdrop may frame the character but must remain quiet;
- negative space is deliberate;
- the product name remains the dominant typographic element;
- pixel-art edges are preserved rather than smoothed into generic high-detail anime rendering;
- cyan and gold are used as sparse directional accents, not as full-screen glow.

## Design constraints for future variations

Future character or banner variations should preserve the adopted identity:

- keep the short icy-blue bob silhouette;
- keep the amber-gold eyes;
- keep the rectangular gate/key hair ornament;
- keep cyan/teal as the dominant project accent and gold as the secondary accent;
- keep the dark hooded coat and geometric hem language recognizable;
- retain deliberate pixel-art edges;
- keep security symbolism tied to gates, credentials, contracts, keys, receipts, or controlled access;
- keep README hero compositions sparse and functional.

Avoid:

- neon circuitry covering the character;
- code rain;
- dense HUD dashboards;
- stock shield / padlock collage imagery;
- tactical-military styling;
- photorealistic rendering;
- high-detail AI-anime rendering that loses the pixel-art silhouette;
- unrelated hairstyles, eye colors, or costume replacements;
- changing the character merely to match another project mascot.

The README hero image itself is the authoritative visual reference for the character and overall public visual direction.
