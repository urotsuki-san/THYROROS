## Character identity

The THYROROS character is the project gatekeeper.

Keep these features:

- short icy-blue / silver-blue bob hair;
- amber-gold eyes;
- small rectangular teal-and-gold gate/key hair ornament;
- dark hooded long coat with cyan piping and restrained gold accents;
- Greek-key trim near the coat hem;
- white shirt, teal necktie, dark pleated skirt, and dark boots;
- small credential / access devices integrated into the outfit;
- glowing access-key card held in one hand;
- calm, slightly confident expression.

Palette:

- near-black navy for the background and coat;
- cyan / teal as the main accent;
- warm gold as the secondary accent;
- off-white for highlights and shirt details.

## Hero composition

The current hero uses this text hierarchy:

```text
THYROROS
AGENT RUNTIME GATE
& FLIGHT RECORDER

IMMUTABLE CONTRACTS  •  MEDIATED EFFECTS  •  VERIFIABLE RECEIPTS

EXTERNAL REFERENCE MONITOR  /  FAIL-CLOSED BY CONTRACT
```

Composition rules:

- keep the product name and copy on the left;
- keep the character on the right;
- keep the circular gate/scope backdrop subtle;
- preserve the open negative space;
- keep `THYROROS` as the largest text;
- preserve pixel-art edges;
- use cyan and gold as accents rather than full-screen glow.

## Design constraints for future variations

Preserve the adopted character identity and README layout unless the repository owner requests a
redesign. In particular, keep the hair silhouette, eye color, hair ornament, coat, geometric trim,
and cyan/gold palette recognizable.

Avoid:

- code rain or neon circuitry covering the character;
- dense HUD overlays;
- stock shield / padlock collage imagery;
- tactical-military styling;
- photorealistic rendering;
- high-detail anime rendering that loses the pixel-art silhouette;
- unrelated hairstyles, eye colors, or costume replacements;
- changing the character only to match another project mascot.

The current README hero image is the visual reference for future variants.
